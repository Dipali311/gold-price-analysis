# 💰 Gold Price Analysis & SMS Alert System

## 📌 Project Overview
This project analyzes gold prices using real-time data and provides a smart decision system to help users decide whether to buy gold or wait.

## 🚀 Features
- 📊 Real-time gold price using yfinance
- 🤖 Decision system (Buy / Wait)
- 📱 SMS alert system using Twilio API
- 🌐 Useful for rural users (no internet needed)

## 🛠 Technologies Used
- Python
- Pandas
- yfinance
- Twilio API

## ⚙️ How it Works
1. Fetch latest gold price
2. Compare with previous day
3. Generate decision
4. Send SMS alert to user
